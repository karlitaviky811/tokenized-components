lib-breadcrumb

Breadcrumb

Navegación de migas basada en rutas de Angular Router. Lee los datos de la ruta activa y emite la URL del padre al navegar.

API

PropiedadFuenteDescripción
parentLabelroute.parent.data['breadcrumb']Label del padre
currentLabelroute.data['breadcrumb']Label actual
OutputTipoDescripción
parentNavigatestringEmite URL del padre al navegar

Notas de uso

El breadcrumb depende del contexto de Angular Router. Configura la ruta con los datos breadcrumb y parentBreadcrumb para que el componente los lea automáticamente.

Uso

// En el routing:
{ path: 'detail', data: { breadcrumb: 'Detalle', parentBreadcrumb: 'Lista' } }

// En el template:
<lib-breadcrumb (parentNavigate)="router.navigateByUrl($event)" />
