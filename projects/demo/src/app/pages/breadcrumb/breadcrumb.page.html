lib-breadcrumb

Breadcrumb

Navegación de migas conectada a Angular Router. Lee automáticamente los datos de la ruta activa y emite la URL del padre al navegar hacia atrás.

API

Dato de rutaClaveDescripción
Label actualdata['breadcrumb']Texto de la miga activa (no clickeable)
Label padredata['parentBreadcrumb']Texto del padre (clickeable)
URL padredata['parentUrl']Ruta a la que navega el padre
OutputTipoDescripción
parentNavigatestringEmite la URL del padre al hacer clic

Variantes

❖ Con padre — ruta activa </>
Lee data['breadcrumb'] y data['parentBreadcrumb'] de la ruta activa · emite parentNavigate al hacer clic

Uso

// En el routing:
{ path: 'detalle', data: {
  breadcrumb: 'Detalle',
  parentBreadcrumb: 'Lista',
  parentUrl: '/lista'
} }

// En el template:
<lib-breadcrumb (parentNavigate)="router.navigateByUrl($event)" />
