List Item lib-list-item

Lista seleccionable con avatars, checkboxes y soporte de selección múltiple.

Inputs

InputTipoDefaultDescripción
itemsLibListItemData[][]Items de la lista
selectedIdsstring[][]IDs seleccionados
multiplebooleantruePermite selección múltiple
disabledbooleanfalseDeshabilita toda la lista
showCheckboxbooleantrueMuestra checkboxes
showAvatarbooleantrueMuestra avatars
showDividersbooleantrueMuestra divisores
checkboxPosition'leading' | 'trailing''trailing'Posición del checkbox
widthstringundefinedAncho de la lista
OutputTipoDescripción
selectionChangestring[]Emite IDs seleccionados
itemClickLibListItemDataEmite item clickeado

Variantes

Básica (solo label + description)

Con avatar

Con checkbox (trailing)

Con checkbox (leading)

LibListItemData interface

interface LibListItemData {{ '{' }}
  id: string;
  label: string;
  description?: string;
  avatarText?: string | null;
  avatarImage?: string | null;
  avatarAlt?: string;
  disabled?: boolean;
{{ '}' }}

Ejemplo de uso

// Básico (solo texto)
<lib-list-item
  [items]="items()"
  [showCheckbox]="false"
  [showAvatar]="false"
  [showDividers]="false"
/>

// Con avatar
<lib-list-item
  [items]="items()"
  [showCheckbox]="false"
/>

// Con selección
<lib-list-item
  [items]="items()"
  [selectedIds]="selectedUsers"
  (selectionChange)="onSelect($event)"
/>
