SharedTable lib-shared-table

Tabla configurable con columnas dinámicas, paginación, templates custom y row click.

Inputs / Outputs

InputTipoDefaultDescripción
columnsSharedTableColumn[]requiredDefinición de columnas
dataT[]requiredDatos de la tabla
captionstringundefinedCaption accesible
emptyStatestring'Sin registros disponibles'Mensaje sin datos
loadingbooleanfalseMuestra spinner
showPaginatorbooleantrueMuestra paginador
pageSizenumber10Filas por página
pageSizeOptionsnumber[][5, 10, 20]Opciones de page size
enableRowClickbooleanfalseHabilita click en filas
totalElementsnumber | undefinedundefinedTotal para paginación server-side
OutputTipoDescripción
rowClickTEmite la fila clickeada
pageChangeTablePageEventEmite al cambiar página

SharedTableColumn interface

interface SharedTableColumn<T> {{ '{' }}
  key: string;         // propiedad del objeto o ID de columna
  header: string;      // texto del encabezado
  align?: 'start' | 'center' | 'end';
  width?: string;      // ej: '120px', '20%'
  cell?: (row: T, index: number) => unknown; // transform fn
{{ '}' }}

Demo (visual)

Ejemplo de uso

// Definir columnas:
columns: SharedTableColumn[] = [
  {{ '{' }} key: 'name', header: 'Nombre' {{ '}' }},
  {{ '{' }} key: 'email', header: 'Correo', width: '250px' {{ '}' }},
  {{ '{' }} key: 'status', header: 'Estado', align: 'center' {{ '}' }},
  {{ '{' }} key: 'amount', header: 'Monto', cell: (row) => '$' + row['amount'] {{ '}' }},
];

// Template:
<shared-table
  [columns]="columns"
  [data]="users"
  [pageSize]="10"
  [enableRowClick]="true"
  (rowClick)="openDetail($event)"
>
  <!-- Custom cell template -->
  <ng-template libCellTemplate="status" let-value>
    <span [class.active]="value === 'Activo'">{{ '{{' }} value {{ '}}' }}</span>
  </ng-template>
</shared-table>
