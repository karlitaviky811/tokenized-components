lib-side-modal

Side Modal

Modal lateral que se desliza desde la derecha. Recibe un componente dinámico como contenido, ideal para paneles de detalle o formularios sin abandonar la vista actual.

API — SideModal Data

PropiedadTipoDescripción
contentType<any>Componente a renderizar
titlestringTítulo del modal
footerType<any> | undefinedComponente footer (opcional)
headerConfigSideModalHeaderConfigConfiguración del header
dialogStateWritableSignal<'open' | 'closed'>Controla la animación de cierre

Uso

const state = signal<'open' | 'closed'>('open');

this.dialog.open(SideModal, {
  data: {
    content: MyDetailComponent,
    title: 'Detalle',
    dialogState: state,
  },
  panelClass: 'side-modal-panel',
});
