BottomSheetStore

Bottom Sheet

Superficie suplementaria anclada al fondo de la pantalla. Se abre mediante BottomSheetStore (CDK Dialog), acepta un componente dinámico como contenido y soporta drag handle configurable. Sigue la especificación M3 Bottom Sheets.

API — BottomSheetStore.open()

ParámetroTipoDescripción
contentType<unknown>Componente Angular a renderizar dentro del sheet
configBottomSheetConfigConfiguración opcional del sheet

BottomSheetConfig

PropiedadTipoDefaultDescripción
showDragHandlebooleantrueMuestra u oculta el indicador de arrastre en el header

Variantes

❖ Con drag handle (default) </>
showDragHandle=true (default) · contenido dinámico · backdrop con scrim
❖ Sin drag handle </>
showDragHandle=false · útil cuando el contexto ya provee un mecanismo de cierre

Uso

// 1. Inyectar el store
private readonly sheetStore = inject(BottomSheetStore);

// 2. Abrir con configuración mínima
this.sheetStore.open(MiContenidoComponent);

// 3. Abrir con opciones
this.sheetStore.open(MiContenidoComponent, {
  showDragHandle: false,
});

// 4. Cerrar programáticamente
this.sheetStore.close();
