lib-chip

Chip

Filter chip de Material 3. Soporta estados outlined/filled, selected, removable e ícono leading.

API

InputTipoDefaultDescripción
labelstring''Texto del chip
variant'outlined' | 'filled''outlined'Variante visual
size'small' | 'medium''medium'Tamaño
selectedbooleanfalseEstado seleccionado
disabledbooleanfalseEstado deshabilitado
removablebooleanfalseMuestra ícono de eliminar
iconstring''Nombre del ícono leading (Material Symbols)
OutputTipoDescripción
removedvoidEmite al presionar el ícono de eliminar

Variantes

❖ Outlined / Filled </>
Outlined · Filled · Selected · Disabled
❖ Con ícono leading </>
icon — Material Symbols name · leading position
❖ Removable </>
removable=true — muestra ícono de cierre
❖ Tamaños </>
size — Small · Medium
❖ Toggle interactivo </>
@for (f of filters(); track f.value) { }
Selección exclusiva — click para cambiar filtro activo

Uso

<lib-chip
  label="Filtro"
  variant="outlined"
  [selected]="isActive"
  icon="filter_list"
  [removable]="true"
  (removed)="onRemove()"
/>
lib-assist-chip

Assist Chip

Assist chip de Material 3. Representa acciones inteligentes o contextuales. No tiene estado seleccionado.

API

InputTipoDefaultDescripción
labelstring''Texto del chip
appearance'outlined' | 'elevated''outlined'Estilo visual
iconstring''Ícono leading (Material Symbols)
disabledbooleanfalseEstado deshabilitado

Variantes

❖ Outlined / Elevated / Disabled </>
appearance — Outlined · Elevated · Disabled
❖ Con ícono </>
icon — Material Symbols name · leading position

Uso

<lib-assist-chip
  label="Agregar al calendario"
  appearance="outlined"
  icon="event"
/>
lib-suggestion-chip

Suggestion Chip

Suggestion chip de Material 3. Presenta sugerencias dinámicas. Es un toggle: soporta estado seleccionado.

API

InputTipoDefaultDescripción
labelstring''Texto del chip
appearance'outlined' | 'elevated''outlined'Estilo visual
selectedbooleanfalseEstado seleccionado
iconstring''Ícono leading (Material Symbols)
disabledbooleanfalseEstado deshabilitado
OutputTipoDescripción
selectedChangebooleanEmite el nuevo estado al hacer click

Variantes

❖ Estados </>
Estado — Unselected · Selected · Elevated · Disabled
❖ Toggle interactivo </>
@for (s of suggestions(); track s.value) { }
Toggle independiente — cada chip mantiene su propio estado

Uso

<lib-suggestion-chip
  label="Angular"
  appearance="outlined"
  [selected]="isSelected"
  (selectedChange)="onToggle($event)"
/>
