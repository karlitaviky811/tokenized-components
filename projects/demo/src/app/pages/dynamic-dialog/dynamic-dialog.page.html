lib-dynamic-dialog

Dynamic Dialog

Dialog de contenido libre con tres secciones independientes: headerTemplate, bodyTemplate y actionsTemplate. Cada sección se proyecta solo si se provee un TemplateRef — el componente es una carcasa sin contenido predefinido.

API — DynamicDialogData

PropiedadTipoDefaultDescripción
headerTemplateTemplateRef—Sección superior: título, ícono, cualquier cabecera
bodyTemplateTemplateRef—Sección central: formularios, listas, contenido rico
actionsTemplateTemplateRef—Sección inferior: botones de acción personalizados

Variantes

❖ Formulario de domicilio — 3 secciones </>
headerTemplate · bodyTemplate con selects y text-field · actionsTemplate con Cancelar / Confirmar
❖ Carga de documentos — acciones por item </>
headerTemplate con ícono · bodyTemplate con lib-list-item · itemClick cierra dialog
❖ Selección de cuentas — lista con avatar </>
headerTemplate · bodyTemplate con lib-list-item avatar + checkbox · actionsTemplate
❖ Identificación — chips Nacional / DIMEX </>
headerTemplate · bodyTemplate con suggestion chips radio + text-field reactivo · actionsTemplate
