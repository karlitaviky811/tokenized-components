Tabs mat-tab-group

Navegación por pestañas con personalización via tokens de Material 3.

Inputs

InputTipoDefaultDescripción
animationDurationstring'500ms'Duración de la animación
disablePaginationbooleanfalseDeshabilita paginación
disableRipplebooleanfalseDeshabilita ripple
headerPosition'above' | 'below''above'Posición del header
colorThemePaletteundefinedColor del tema

Variantes

Tabs básicos

Contenido del primer tab Contenido del segundo tab Contenido del tercer tab

Con iconos

home Inicio Contenido de Inicio person Perfil Contenido de Perfil settings Configuración Contenido de Configuración

Con color (primary)

Lista de elementos activos Lista de elementos pendientes Historial de actividades

Header position below

Contenido de Archivo Contenido de Editar Contenido de Ver

Ejemplo de uso

<mat-tab-group animationDuration="300ms">
  <mat-tab label="Primero">
    Contenido del primer tab
  </mat-tab>
  <mat-tab label="Segundo">
    Contenido del segundo tab
  </mat-tab>
</mat-tab-group>
