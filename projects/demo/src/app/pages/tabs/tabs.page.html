mat-tab-group

Tabs

Navegación por pestañas de Angular Material 3, con tokens Credix aplicados. Soporta íconos, posición del header y animaciones configurables.

API

InputTipoDefaultDescripción
animationDurationstring'500ms'Duración de la animación de cambio de tab
disablePaginationbooleanfalseDeshabilita paginación cuando hay overflow
disableRipplebooleanfalseDeshabilita el efecto ripple
headerPosition'above' | 'below''above'Posición del header de tabs
colorThemePaletteundefinedColor del tema Material

Variantes

❖ Básico </>
Contenido del primer tab Contenido del segundo tab Contenido del tercer tab
mat-tab-group · label como string · comportamiento por defecto
❖ Con ícono </>
home Inicio Contenido de Inicio person Perfil Contenido de Perfil settings Configuración Contenido de Configuración
ng-template mat-tab-label · ícono Material Symbols + texto
❖ Header inferior </>
Contenido de Archivo Contenido de Editar Contenido de Ver
headerPosition="below" · el indicador activo aparece sobre el header

Uso

<mat-tab-group animationDuration="300ms">
  <mat-tab label="Primero">Contenido del primer tab</mat-tab>
  <mat-tab label="Segundo">Contenido del segundo tab</mat-tab>
</mat-tab-group>
