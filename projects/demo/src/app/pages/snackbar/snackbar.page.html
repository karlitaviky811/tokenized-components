LibSnackbarStore

Snackbar

Notificaciones temporales que informan al usuario sobre una operación completada o en curso. Aparecen en la parte inferior de la pantalla y desaparecen automáticamente. Siguen la especificación M3 Snackbar. Se muestran vía LibSnackbarStore, que envuelve MatSnackBar.

API — LibSnackbarStore

MétodoParámetrosDescripción
open(message, options?)string, LibSnackbarOpenOptionsSnackbar con texto. Retorna MatSnackBarRef
openWithAction(message, actionLabel, options?)string, string, LibSnackbarOpenOptionsSnackbar con texto + botón de acción
dismiss()—Cierra el snackbar activo

Variantes

❖ Solo texto (1 línea) </>
Mensaje simple · auto-dismiss 4s · sin acción ni cierre
❖ Texto + acción </>
Acción inline a la derecha del texto
❖ Texto + cierre </>
showClose=true · botón X de 48×48 px
❖ Texto + acción + cierre </>
Acción inline + botón X
❖ Longer action (acción debajo) </>
longerAction=true · acción alineada abajo-derecha · altura 112px
❖ Longer action + cierre </>
longerAction=true · showClose=true
❖ Sin auto-dismiss </>
duration=0 · showClose=true · persiste hasta que el usuario cierre
❖ Duración personalizada (8s) </>
duration=8000

Uso

// Inyectar el store
private readonly snackbar = inject(LibSnackbarStore);

// Solo texto
this.snackbar.open('Guardado correctamente.');

// Con acción (suscribirse para el callback)
const ref = this.snackbar.openWithAction('Elemento eliminado.', 'Deshacer');
ref.onAction().subscribe(() => this.restore());

// Con cierre manual
this.snackbar.open('Procesando...', { duration: 0, showClose: true });

// Con acción larga debajo del texto
this.snackbar.openWithAction(
  'No se pudo conectar.',
  'Reintentar conexión',
  { longerAction: true, showClose: true },
);

// Cerrar programáticamente
this.snackbar.dismiss();
