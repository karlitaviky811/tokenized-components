lib-divider

Divider

Separador visual horizontal o vertical. Crea separación visual entre secciones de contenido.

API

InputTipoDefaultDescripción
orientation'horizontal' | 'vertical''horizontal'Dirección del divisor

Variantes

❖ Horizontal </>
Sección A Sección B
orientation="horizontal" (default) — separador de ancho completo
❖ Vertical </>
Izquierda Derecha
orientation="vertical" — separador de alto completo del contenedor

Uso

<lib-divider orientation="horizontal" />
