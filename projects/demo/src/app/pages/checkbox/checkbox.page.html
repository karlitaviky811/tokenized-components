lib-checkbox

Checkbox

Checkbox con soporte de estados indeterminate y error. Compatible con formularios reactivos.

API

InputTipoDefaultDescripción
checkedbooleanfalseEstado marcado
indeterminatebooleanfalseEstado indeterminado
disabledbooleanfalseDeshabilitado
errorbooleanfalseMuestra estado de error
OutputTipoDescripción
checkedChangebooleanEmite al cambiar estado

Estados

❖ Todos los estados </>
Default Checked Indeterminate Disabled Error
Default · Checked · Indeterminate · Disabled · Error
❖ Disabled selected </>
Disabled checked Disabled indeterminate
Combinaciones disabled + checked / indeterminate

Uso

<lib-checkbox
  [checked]="accepted()"
  (checkedChange)="onAccept($event)"
>Acepto los términos</lib-checkbox>
