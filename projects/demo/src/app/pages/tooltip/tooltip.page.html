Integración en una vista

Importante antes de integrarlo: lib-tooltip es PRESENTACIONAL. Solo pinta la burbuja. No trae trigger, no se ancla a un elemento, no posiciona y no aporta accesibilidad. La vista que lo consume debe aportar tres cosas:

ResponsabilidadQuién la cubreCómo
Estilo de la burbujalib-tooltiptext, type, maxWidth
Visibilidad / triggerLa vistasignal + mouseenter / focus
PosicionamientoLa vistaancla position: relative + burbuja absolute
AccesibilidadLa vistaaria-describedby + role="tooltip"

Caso modelo: hint en etiquetas de formulario

Patrón habitual: un ícono de ayuda junto a la etiqueta que revela el tooltip en hover y en foco de teclado. El foco es obligatorio, si no el hint queda inaccesible sin mouse.

Building Blocks

Uso

Burbuja suelta

<lib-tooltip text="Más información" type="single-line" />

Integrado en una vista

Estado de visibilidad en el componente contenedor:

private readonly activeHint = signal<string | null>(null);

isHintVisible(id: string): boolean {
  return this.activeHint() === id;
}

showHint(id: string): void { this.activeHint.set(id); }
hideHint(): void { this.activeHint.set(null); }

Ancla, trigger y wiring de accesibilidad en la plantilla:

<span class="tooltip-demo__anchor">
  <button
    type="button"
    class="tooltip-demo__trigger"
    aria-describedby="hint-cupo"
    (mouseenter)="showHint('cupo')"
    (mouseleave)="hideHint()"
    (focus)="showHint('cupo')"
    (blur)="hideHint()"
  >
    <span class="material-symbols-outlined" aria-hidden="true">info</span>
  </button>

  @if (isHintVisible('cupo')) {
    <span class="tooltip-demo__bubble" id="hint-cupo" role="tooltip">
      <lib-tooltip text="Monto máximo disponible" />
    </span>
  }
</span>

Posicionamiento, que el componente no resuelve:

.tooltip-demo__anchor {
  position: relative;
  display: inline-flex;
}

.tooltip-demo__bubble {
  position: absolute;
  bottom: calc(100% + 6px);
  left: 50%;
  transform: translateX(-50%);
  z-index: 10;
  pointer-events: none;
}
