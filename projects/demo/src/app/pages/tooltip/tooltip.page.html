lib-tooltip

Tooltip

Tooltip informativo con soporte single-line y multi-line. Muestra información contextual sin ocupar espacio en la UI.

API

InputTipoDefaultDescripción
textstring'Supporting text'Contenido del tooltip
type'single-line' | 'multi-line''single-line'Variante
maxWidthstring | nullnullAncho máximo (multi-line)

No expone outputs. Es un componente PRESENTACIONAL: solo pinta la burbuja. El trigger, la visibilidad y el posicionamiento son responsabilidad del componente consumidor.

Uso

Burbuja suelta

<lib-tooltip text="Más información" type="single-line" />

Integrado en una vista

// Estado de visibilidad en el componente contenedor
private readonly activeHint = signal<string | null>(null);

isHintVisible(id: string): boolean { return this.activeHint() === id; }
showHint(id: string): void { this.activeHint.set(id); }
hideHint(): void { this.activeHint.set(null); }

// Template
<span class="tooltip-anchor" style="position: relative; display: inline-flex;">
  <button
    aria-describedby="hint-cupo"
    (mouseenter)="showHint('cupo')"
    (mouseleave)="hideHint()"
    (focus)="showHint('cupo')"
    (blur)="hideHint()"
  >
    <span class="material-symbols-outlined">info</span>
  </button>
  @if (isHintVisible('cupo')) {
    <span style="position: absolute; bottom: calc(100% + 6px);" id="hint-cupo" role="tooltip">
      <lib-tooltip text="Monto máximo disponible" />
    </span>
  }
</span>
