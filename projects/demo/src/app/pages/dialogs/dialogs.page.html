lib-confirm

Dialog

Modal de confirmación abierto via CDK Dialog. Soporta variantes basic, list y scrollable-list, con ícono superior, botón primario filled y proyección de contenido custom via bodyTemplate.

API — ConfirmModalData

PropiedadTipoDefaultDescripción

primaryFilledbooleanfalseBotón confirmar con variant filled
bodyTemplateTemplateRef—Contenido custom proyectado antes de las acciones
labelButtonCancelstring'Cancelar'Label botón cancelar
labelButtonConfirmstring—Label botón confirmar
