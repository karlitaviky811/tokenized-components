lib-button

Button

Botón con variantes de Material 3, formas, tamaños y soporte de toggle.

API

Input Tipo Default Descripción
label string '' Texto del botón
variant 'filled' | 'outlined' | 'tonal' | 'text' | 'elevated' 'filled' Variante visual
size 'xsmall' | 'small' | 'medium' | 'large' | 'xlarge' 'medium' Tamaño
shape 'round' | 'square' 'round' Forma del borde
fullWidth boolean false Ocupa 100% del contenedor
disabled boolean false Estado deshabilitado
type 'button' | 'submit' | 'reset' 'button' Tipo HTML nativo
toggle boolean false Habilita modo toggle
selected boolean false Estado seleccionado (toggle)
icon string '' Nombre del ícono
iconPosition 'leading' | 'trailing' 'leading' Posición del ícono
contentAlign 'start' | 'center' | 'end' 'center' Alineación del contenido

Variantes × Tamaños

❖ Filled </>
Type=Filled — Fila 1: Round · Fila 2: Square
❖ Outlined </>
Type=Outlined — Fila 1: Round · Fila 2: Square
❖ Tonal </>
Type=Tonal — Fila 1: Round · Fila 2: Square
❖ Text </>
Type=Text — Fila 1: Round · Fila 2: Square
❖ Elevated </>
Type=Elevated — Fila 1: Round · Fila 2: Square

Estados

Uso

<lib-button
  label="Guardar"
  variant="filled"
  shape="square"
  size="medium"
  [fullWidth]="true"
  [disabled]="form.invalid"
  type="submit"
/>
