lib-confirm · lib-dynamic-dialog

Dialog

Modal de confirmación via CDK Dialog. Las primeras variantes usan ConfirmModal con contenido fijo; las últimas tres usan DynamicDialog con las tres secciones independientes proyectadas via TemplateRef.

API — ConfirmModalData

PropiedadTipoDefaultDescripción
titlestring—Título del modal
contentstring—Texto de soporte
descriptionstring—Descripción adicional (alias de content)
showTopIconbooleanfalseMuestra ícono superior centrado
topIconNamestring'check_box'Nombre del ícono Material Symbols
primaryFilledbooleanfalseBotón confirmar con variant filled
bodyTemplateTemplateRef—Contenido custom proyectado antes de las acciones
labelButtonCancelstring'Cancelar'Label botón cancelar
labelButtonConfirmstring—Label botón confirmar

API — DynamicDialogData

PropiedadTipoDefaultDescripción
headerTemplateTemplateRef—Sección superior: título, ícono, cualquier cabecera
bodyTemplateTemplateRef—Sección central: formularios, listas, contenido rico
actionsTemplateTemplateRef—Sección inferior: botones de acción personalizados
